## 4. 文体约定

1. **规则数值**：`Base Rating: 30%` → "基础值：30%"，数字不变。
2. **属性写法**：`STR×5` → "力量×5"，`POW×5` → "意志×5"。
3. **检定写法**：`make a DEX×5 test` → "进行一次敏捷×5 检定"。
4. **表格**：Markdown 表格结构原样保留，只译文字。
5. **标题编号**：`## 2.2.1 STEP 0` → `## 2.2.1 第 0 步`，编号不动。
6. **第二人称**：规则解释用"你"，示例用"你的主角"。
7. **OGL 正文**：末页许可全文**保留英文**，不翻译（法律文本，翻译会引入歧义），只在前加一句中文说明。

## 5. 已知风险点

- **Protagonist 不是 Investigator**：CE 刻意避开 CoC 的"调查员"，一律"主角"
- **Game Moderator 不是 Keeper**：一律"主持人"
- **六属性 vs 七属性**：看到 SIZ/EDU/APP 一律视为错误
- **Lethality Rating** 是高伤害武器的一次性判定机制，不是"致死率"
- **Bonds** 是角色关系网，不是"债券"
- **Breaking Point** 是 SAN 归零前的临界值，不是"断点"
- 技能表里带 `(Type)` 的是可指定子类的技能，如 `Science (Biology)` → "科学（生物学）"
